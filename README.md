# HW 4: Trees (Binary, AVL, and Algorithms)

## Overview
This project is part of the course **Data Structures & Object-Oriented Design** and focuses on **recursive algorithms on binary trees**.  
The assignment implements a function that determines whether **all root-to-leaf paths in a binary tree have the same length**, a property referred to as *equal paths*.

The homework emphasizes **recursive reasoning, tree traversal, and careful handling of base cases**, without relying on loops or extra data structures.

## Features
- Recursive traversal of binary trees
- Detection of equal root-to-leaf path lengths
- Clean separation between implementation and testing
- Test cases validating correctness across multiple tree structures
- Build automation using a Makefile
